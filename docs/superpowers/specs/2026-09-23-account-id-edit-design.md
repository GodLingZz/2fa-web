# 注册后修改账号 ID 设计

## 背景

账号管理工作台已有账号编辑表单，但账号 ID 输入框只读，后端更新接口也只接受当前 ID，因此已注册账号无法改名。

## 目标

允许管理员在编辑账号时修改账号 ID，同时保持所有关联 Token 的账号归属一致。

## 方案

- 将编辑弹窗中的账号 ID 输入框改为可编辑，并清楚提示新 ID 必须唯一。
- 现有 `PUT /api/admin/accounts` 请求同时携带当前账号 ID 与目标账号 ID。
- 后端验证目标 ID 非空且未被其他账号占用；相同 ID 视为普通资料更新。
- 通过 D1 原子批处理同时更新 `accounts.account_id` 与所有关联的 `tokens.account_id`。Token 状态不影响改名同步；现有“同步可用 Token”选项仍只控制密码和 2FA 密钥同步。
- 成功后刷新账号和 Token 列表；冲突或账号不存在时返回清晰错误，数据不发生部分更新。

## 验收标准

1. 编辑账号后可以保存新 ID，工作台显示新 ID。
2. 改名后该账号的所有 Token（可用、已使用、已停用）都显示新 ID，Token 记录本身不丢失。
3. 目标 ID 已被其他账号使用时，保存失败并显示提示，双方账号和 Token 归属保持不变。
4. 仅修改密码、密钥、状态或备注时，原有编辑行为保持不变。

## 验证范围

覆盖成功改名、目标 ID 冲突和保留现有编辑行为；运行项目现有测试，并对前端表单与 D1 更新路径做检查。
